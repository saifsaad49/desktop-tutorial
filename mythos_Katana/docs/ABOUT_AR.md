## الفكرة بكلمة وحدة

أغلب وكلاء الذكاء الاصطناعي يجاوبون مرة ويسكتون.
يشوفون خطأ 500 بالموقع ويكولون "هذا RCE خطير!" وهو أصلاً مو شي.

**mythos_Katana** يكسر هاي العادة. هو **مجلس من ستة عقول** يشتغلون سوة على
هدف واحد، وما يوقفون إلا لما يوصلون لدليل حقيقي.

---

## المشكلة اللي يحلها

بالشغل الحقيقي، أنت ما تثق بمحلل واحد. تسوي **غرفة عمليات** — واحد يهاجم،
واحد يدافع، واحد يطلب دليل، وواحد يحسم القرار.

هذا المشروع هو **غرفة العمليات هاي بس على شكل كود**.

القاعدة الوحيدة: **ماكو نتيجة تطلع بدون دليل.**

---

## المجلس الستة — شلون يفكرون

كل جولة، الوكيل يقترح **فرضية وحدة بس**، والمجلس يفصّلها:

| العضو | شغله |
|---|---|
| 🔴 **المهاجم** | "هذا شلون يكدر ينكسر؟" |
| 🔵 **المدافع** | "هذا ليش ما ينكسر — WAF، صلاحيات، إعدادات" |
| 🟡 **المحقق** | "جيبلي الدليل. لا لوگ = لا ادعاء" |
| ⚖️ **القاضي** | يحسم: `CONFIRMED` / `REJECTED` / `NEEDS_MORE_TESTING` + الخطورة |
| 🌐 **الباحث** | يجيب CVEs والوثائق (محدود، محفوظ، يحترم robots.txt) |
| ♾️ **المُصِر** | إذا انرفض، **ما يستسلم** — يغيّر الخطة ويرجع |

الحلقة: `فرضية ← فحص ← نقاش ← تحويل المسار`

---

## 90 أداة فحص

المشروع عنده **90 أداة** مسجلة: فحص headers، SSL، DNS، ساب دومينات،
CSP، CORS، تسريبات `.env` و `.git`، openapi، rate limiting، clickjacking،
WAF، Cloudflare، سلسلة التوريد، وغيرها هواي.

---

## الذاكرة — ما يعيد نفس الشي

الوكيل يتذكر شنو جرب. كل جولة ياخذ **فحص ما جربه قبل**، وكل شي ينحفظ.
من يخلص الـ 30 فحص، ما يصفن — **يتطور لفرضيات أعمق** ويكمل.

---

## ما يوكف أبداً

```bash
python -m agent.persistent
```
يشتغل للأبد، يدور، يحلل، يناقش، ويوثق — لحد ما يلگه ثغرة فعلية.

ومعاه **مشرف (supervisor) صفر توكن** — إذا وگف لأي سبب، يرجعه تلقائياً.

---

## العقل الحقيقي (اختياري)

الفحص نفسه **ما يصرف ولا توكن** — هو بايثون و curl بس.

بس إذا تريد المجلس **يفكر فعلياً** بنموذج حقيقي، ربطه بأي مزود:
- Claude (Anthropic)
- أي بوابة OpenAI-compatible
- **Ollama محلي** = تفكير حقيقي بصفر تكلفة

وإذا النموذج فصل أو انحظر؟ **الحلقة ما توقف** — ترجع للقوالب وتسجل السبب الدقيق.

---

## فلتر الجودة — ما يخربطون

كل نقاش يمر على فلتر قبل ما ينحفظ. يرفض:
- نقاش ناقص أعضاء
- كلام خارج الأمن السيبراني
- قاضي بلا حكم
- نص مشوّش أو فيه رسالة خطأ مسرّبة

وإذا انرفض، يعيد المحاولة مرة قبل ما يرجع للقوالب.

## تشغيله من جهازك

```bash
git clone https://github.com/saifsaad49/desktop-tutorial.git
cd desktop-tutorial/mythos_Katana
pip install -r requirements.txt

export OPENAI_API_KEY=مفتاحك
chmod +x scripts/*.sh
nohup ./scripts/supervise.sh > /dev/null 2>&1 &
```

من جهازك **ما ينطفي أبداً** — لأن جهازك ما ينمسح.

**المتابعة:**
```bash
tail -f .katana/scan.log          # الجولات الحية
tail -f .katana/supervisor.log    # الإرجاعات
```
